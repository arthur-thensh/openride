# Fichiers GPX locaux

Ce dossier sert aux imports/exports GPX d'OpenRide.

- `import.gpx` : fichier chargé avec la touche `I` si aucun GPX n'est passé au lancement.
- `openride-route.gpx` : dernier itinéraire exporté avec `E`.
- `openride-recording.gpx` : dernière trace GPS enregistrée avec `G`.

Les fichiers `.gpx` personnels de ce dossier ne sont pas suivis par Git.
